📘 Assessment Questions – Queue Implementation in C


💻 This repository contains C programs based on Queue Data Structure, created as part of programming practice and academic assessment work.


🎯 About This Repository


The purpose of this repository is to understand and implement different types of Queue operations using the C programming language.


Each program demonstrates the basic working, operations, and concepts of Queue Data Structures.

▶️ How to Run


1. Clone the repository:


git clone https://github.com/gadediksha/Assessment_questions


2. Open the project in your code editor.


3. Compile the required C file:


gcc Linear_queue.c -o output



4. Run the program:


./output



For Windows, use output.exe to run the compiled program.
